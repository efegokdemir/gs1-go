# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, focus on the technical merits,
and keep discussions about the code and the specifications. Harassment,
personal attacks and discriminatory language are not tolerated.

Reports can be sent privately to the maintainer via the contact details on
the repository profile. Reports are handled confidentially.
